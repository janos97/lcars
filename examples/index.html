Palette

Every colored piece reads --lcars-c. Set it with a .lcars-c-* class — named swatches or semantic roles. Themes remap the roles; swatches stay fixed (except under red alert, where everything turns red).

Themes

One theme per series, from Enterprise to Picard, plus red alert. Apply data-lcars-theme="…" to <html> or to any element — each preview below is scoped that way. Some themes also retune geometry (bar thickness, corner radii) to match their era.

Frame

The sidebar-elbow-bar construction. Include only the parts you need: drop the top pieces for a header, the bottom pieces for a body, keep both for a bracketed panel. .lcars-frame--right mirrors it. Everything is sized by tokens such as --lcars-side, --lcars-bar and --lcars-inner-radius.

Blocks & bars

.lcars-block is the basic colored slab with its label in the bottom-right. .lcars-bar lays segments out in a strip; weight them with .lcars-grow-*, cap the ends with .lcars-round-start / -end, and drop a .lcars-bar__title in between.

Meters

Segmented level bars driven by --lcars-value (0–1). With lcars.js loaded, aria-valuenow drives it for you.

Forms

Native controls, restyled. aria-invalid="true" switches to the alert color.

SVG

For shapes boxes can't draw, use inline SVG with .lcars-svg: shapes are painted with --lcars-c, so color classes and themes apply, and shapes with role="button" behave like buttons (Enter/Space with lcars.js). See the X/Y control recipe.

Layout

Small primitives: .lcars-app (full-page column of frames), .lcars-stack, .lcars-cluster, .lcars-split and the auto-fit .lcars-grid (tune with --lcars-grid-min). All spacing comes from --lcars-space.

JavaScript (optional)

The CSS stands alone. lcars.js is a ~9 kB ES module that wires up data attributes and exposes a small API.

<span data-lcars-clock></span>            live clock ("hm" hides seconds)
<span data-lcars-stardate></span>         stardate, YYYY.DDD
<div class="lcars-data" data-lcars-cascade="48"></div>
<button data-lcars-set-theme="ds9">        switch theme ("" = default)
<select data-lcars-theme-select>          theme picker, fills itself with every theme
<button data-lcars-toggle-alert>           red alert on/off
<body data-lcars-sound>                   sounds on clicks (tap | confirm | deny | alert | red-alert | ready)

import LCARS from "lcars";                 // or "./dist/lcars.js"
LCARS.setTheme("voy");                    // ids: LCARS.THEMES.map(t => t.id)
LCARS.setAlert(true);
LCARS.beep("confirm");
LCARS.setSounds({ "red-alert": "/sfx/klaxon.ogg" }); // optional: your own audio files
LCARS.init(element);                       // upgrade content you rendered yourself
